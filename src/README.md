# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities
- Share an activity through Facebook, X, email, or a copied link without logging in
  - Shared links highlight the selected activity when opened.
  - If automatic copying is unavailable, select and copy the displayed link manually.
